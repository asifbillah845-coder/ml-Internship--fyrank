Abstract

This study asks which existing content pages should be reviewed first when editorial resources are limited. We use the bundled anonymized FlyRank content-refresh snapshot of 30,000 pages and define observed decline as trend_direction == down. A transparent refresh score is compared with Logistic Regression, Decision Tree and Random Forest models under a client-holdout evaluation with leakage checks. Random Forest achieved Precision@50 of 0.740 versus 0.240 for the baseline and ROC-AUC of 0.750 on the held-out test set. The output is a ranked, human-review decision-support queue rather than a causal claim about search-engine behavior.

Research question

Which existing pages should be reviewed first for refresh based on measurable signals associated with observed decline?

Data & safety

The bundled release contains 30,000 anonymized rows and 44 columns. The preparation contract requires positive 90-day impressions and content age ≥90 days and removes duplicate content IDs. Label-derived fields trend_direction and trend_pct are excluded from model features. content_id and client_id are identifiers only.

Methodology

We compared a transparent baseline, Logistic Regression, Decision Tree and Random Forest. The primary metric is Precision@50 because the operational queue is small. Validation uses a client holdout so a client's pages do not appear in both train and test. Random state: 42.

Signal audit

Volume and CTR/position opportunity were directionally supported. The simple staleness flag was not confirmed in this snapshot: pages ≥180 days since update had a lower observed decline rate than the non-stale group. This is a useful negative finding and prevents overclaiming.

Model interpretation

The strongest Random Forest feature importances included days with impressions, log impressions, average position and content age. These are model-useful signals, not proven causal drivers.

Action playbook

  1. Review high-confidence candidates first.
  2. For visible low-CTR pages, inspect intent/snippet alignment manually.
  3. For low-engagement candidates, inspect usefulness, clarity and page experience.
  4. Treat age/staleness as supporting evidence only.
  5. Keep low-confidence items in monitoring unless editorial context justifies action.
Honest framing: this system supports review prioritization. It does not prove that refreshing a page will improve traffic or rankings and does not predict Google's algorithm.

Artifacts

Reproducibility

From the repository root: pip install -r requirements.txt then python scripts/run_all.py.

Limitations

This is an observational snapshot, not a true future-window forecasting study. Results may change with a new data release, client mix or distribution. A future longitudinal release should be used for temporal validation before production use.
